The ``1-my_list`` module
========================

Using ``MyList``
-----------------

Import MyList:

    >>> MyList = __import__('1-my_list').MyList

Create an empty MyList; it behaves like a normal list:

    >>> my_list = MyList()
    >>> print(my_list)
    []
    >>> isinstance(my_list, list)
    True

Append elements:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> len(my_list)
    5

print_sorted() prints a sorted copy, without changing the original list:

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

print_sorted() on an empty list prints an empty list:

    >>> MyList().print_sorted()
    []

print_sorted() works with negative and duplicate numbers:

    >>> ml = MyList()
    >>> ml.append(3)
    >>> ml.append(-1)
    >>> ml.append(3)
    >>> ml.append(0)
    >>> ml.print_sorted()
    [-1, 0, 3, 3]
