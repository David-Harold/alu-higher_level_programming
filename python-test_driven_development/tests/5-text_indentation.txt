The ``text_indentation`` function
==================================

Import the function:

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Basic usage:

    >>> text_indentation("Hello. How are you? I am fine: thanks.")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    I am fine:
    <BLANKLINE>
    thanks.
    <BLANKLINE>

No trailing punctuation, no extra blank line at the end:

    >>> text_indentation("Hello there")
    Hello there

text is not a string:

    >>> text_indentation(89)
    Traceback (most recent call last):
    TypeError: text must be a string

    >>> text_indentation(["Hello"])
    Traceback (most recent call last):
    TypeError: text must be a string

Empty string prints nothing:

    >>> text_indentation("")
